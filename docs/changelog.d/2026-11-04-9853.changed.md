- **Invoices up to 250 EUR gross no longer need the client's address**
  (system_3 #9853, from #9835). A client's postal address is now optional
  at create and update; only the name is required. Issuing checks the
  address against the invoice's gross total: up to 250.00 EUR the invoice is
  a §33 UStDV Kleinbetragsrechnung and is issued without it, and the PDF's
  recipient block is the name alone. Above 250.00 EUR (or in a currency
  other than EUR) issuing still refuses with `client_incomplete`, and the
  message now names the total, the 250,00 € threshold and the fix (add the
  address).

- Invoicing: a refused hand-entered payment or expense, and a refused
  edit of one, now answers a code of its own for each cause, the request
  field it is about (`field`), and the number its sentence names
  (`limit`). The codes include `invalid_date`, `date_in_future`,
  `date_too_early`, `invalid_amount`, `amount_too_large`, `too_long`,
  `hidden_characters`, `no_letter_or_digit`, `invalid_email`,
  `invalid_choice`, `no_such_client`, `needs_new_client`,
  `client_and_new_client`, `invalid_category` and `required`. Before
  this, most of them shared `invalid_field`. A length and a tab or other
  hidden character are now told apart. The message is unchanged
  (system_3 #12300).

- **An N26 import keeps the payer's IBAN, and later payments link to that
  client by it** (system_3 #11551-A2, #12085). An incoming payment from an N26
  CSV row with a valid `Partner Iban` stores it, normalised, in the new
  `invoicing_payments.sender_iban`, which is never in an API response or an
  audit row. The confirm step links the payment to the owner's own client with
  that IBAN. "Add payers…" gives a new client the IBAN when every payment of
  its row carries the same one and no other client in the book has it. Linking
  or removing a payment clears its copy. Outgoing rows keep no IBAN, and no
  error, log line or import summary quotes one. Nothing is backfilled.

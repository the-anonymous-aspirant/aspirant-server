- **A payment entered by hand can add its payer to the client book**
  (system_3 #10547, under #10539). `POST /invoicing/payments/manual` takes an
  optional `new_client_name`, instead of `client_id`: the client is created
  and the payment linked to it in one transaction, both or neither. A name
  that is already in the book (case, accents, `. , - '` and spacing aside)
  is refused with 409 `client_exists` and that client, never duplicated.
  The create still never makes an invoice draft.

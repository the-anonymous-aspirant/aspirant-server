The Book's counting selection is stored per user, with named presets and a built-in "Work only" (paid work in, every expense category except Private out), which cannot be changed or deleted (system_3 #10555-A3). Every book gains a built-in "Private" expense category, listed last, which cannot be created again and is never counted: no selection or preset may include it, and the bookkeeping report leaves Private expenses out. New endpoints: GET/PUT /invoicing/book/selection, POST /invoicing/book/presets, PUT/DELETE /invoicing/book/presets/:id, each write audited.

Each payment in `GET /invoicing/payments` now names the invoice it is on, as `invoice`: `null`, or `{ "id", "status", "invoice_number" }` (system_3 #10666, design §3.143 Decisions 3 and 5). It names the issued invoice if one covers the payment, otherwise the newest draft, never a cancelled one, so Transactions can read "Invoice 2026-014" or "Draft". `on_invoice` and `on_issued_invoice` are unchanged.

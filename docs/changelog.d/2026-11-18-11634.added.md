- **The book report can be exported for one month** (system_3 #11634, #11497
  item 12; the operator's c70883 on #10985). `GET
  /invoicing/export/book-report.csv` takes an optional `month=YYYY-MM`. With
  it, only the entries paid in that month are counted: the rows are the whole
  book's, and the columns are that month and Gesamt. The month's column is
  there even when nothing was counted in it. The file is named
  `book-report-<selection>-month-YYYY-MM-<stamp>.csv`, and the export's audit
  row names the month. A month that is not a calendar month written YYYY-MM is
  refused with 400 before anything is read, and no export is recorded. Without
  the parameter the file is unchanged.

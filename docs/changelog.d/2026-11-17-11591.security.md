- **A deleted account's identifiers are erased thirty days after deletion**
  (system_3 #11591, from the operator's answer on #11380). Deleting a user
  only soft-deletes the row, so its username, address, password hash, comment
  and avatar stayed in the table for good. An hourly sweep, started at boot,
  now takes each account deleted more than thirty days ago and sets the
  username to `deleted-<id>`, empties the other four fields and stamps a new
  nullable column, `users.identifiers_erased_at`, which is also what makes a
  second pass a no-op. The avatar file is removed from asset storage unless
  another account still carries the same picture; a file that cannot be
  removed leaves the row for the next pass. The sweep logs user ids only.
  The first pass after this ships also erases accounts deleted more than
  thirty days earlier.

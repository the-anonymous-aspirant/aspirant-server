- **API responses carry `Cache-Control: no-store` by default** (system_3
  #11494). `middleware.NoStoreByDefault` is registered first in the route
  table, so every response says it, the 401, 403 and 404 included; the
  handlers that set their own value, all `private`, keep it. A response with
  no `Cache-Control` left the decision to the browser and to any proxy in
  front of the server, which is how a second tap of "Bookkeeping report (CSV)"
  could return the earlier file instead of a new export. A test walks every
  registered route and fails on one that answers without `no-store` or
  `private`.

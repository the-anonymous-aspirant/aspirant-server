- **N26 PDF import for the invoicing app** (system_3 #9812). One importer
  reads both N26 document kinds — per-transfer confirmation PDFs and account
  statements — next to the PayPal CSV import and manual entry. Parsing and
  storing are separate steps: `POST /invoicing/payments/import-n26/parse`
  returns candidate rows (flagging ones already imported or colliding on
  date+amount with any stored payment) and nothing is persisted until the
  owner confirms rows via `POST /invoicing/payments/import-n26/confirm`,
  which dedupes by the N26 operation id and audit-logs the import. Text is
  extracted with poppler's pdftotext (now in the runtime image; evaluation
  in docs/DECISIONS.md), outside the Go process, with a 5 MB per-file cap
  and a 10 s timeout.

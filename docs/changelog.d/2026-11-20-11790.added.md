- **The expense list says whether each expense has a receipt** (system_3
  #11630-A1, #11790). Every expense from `GET /invoicing/expenses`, including
  the `removed=true` view, carries `has_receipt`: true when a receipt is
  attached, false when none is. It comes from one read of the owner's own
  receipt ids, never another book's, and never a receipt's bytes. Nothing is
  written. Other responses that carry an expense (create, edit) leave the field
  out rather than send false, because they have not looked.

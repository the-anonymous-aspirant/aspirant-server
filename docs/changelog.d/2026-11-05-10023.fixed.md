- **Invoicing: the PayPal import reads PayPal's statement CSV** (system_3
  #10023, found by #9874 on the operator's real export). That export names
  the Type column "Description", has no Status column, and can open with a
  BOM whose bytes were re-encoded as text, so the import refused it as "not
  a PayPal activity export: missing column(s) date, type, status". The
  header match now peels either BOM spelling and the quotes around it,
  "Description" reads as the type, and a file needs either Status (checked
  as before) or a statement's Balance column (a statement lists posted rows
  only). A file with neither is still refused.

- **Deleting a user removes their constellation relationship edges** (system_3
  #11427, from the security review of #11384). `User.DeleteUser` now
  hard-deletes every `constellation_relationships` row with the user at either
  end, in every room and cleared ones included, in the same transaction as the
  rest of the delete. A room's state is built from its edges without checking
  membership, so the other players were still served edges to a user who no
  longer had a seat. The rooms' undo and redo history is kept: it holds bare
  ids, and an edge to a non-member cannot be set again.

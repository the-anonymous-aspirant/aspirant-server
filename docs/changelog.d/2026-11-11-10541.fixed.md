- **N26 import now also reads the real German statement layout** (system_3
  #10541, under #10534). The statement importer was built against a
  look-alike Italian layout; a real N26 statement prints the counterparty
  first, the booking date in the middle and the amount glued to its currency
  mark, so every real German statement read zero transactions. The importer
  now reads both layouts, recognises the Kontoaktivität export as the same
  document kind, and uses the German layout's value date (Wertstellung) as
  the payment date. Money moving between the account holder's own main
  account and Spaces (Round-ups, Monthly Rules, plain transfers to or from a
  Space) is reported as a left-out row; every other transaction type is
  offered, on the main pages and the per-Space pages alike, so a payment
  type the importer has not seen before is shown rather than dropped. The
  Italian statement path is unchanged.

`PATCH /invoicing/payments/:id` now accepts `new_client_name` on a hand-entered payment. It adds the payer to the client book and links the payment, in the same transaction and with the same rules and refusals as creating one (system_3 #10696, design §3.143 Decision 5: "Paid by" keeps §3.142 in edit mode). On an imported payment it is refused with `bank_fact_field`, because there the payer is the bank's record. The response carries `client` when one was added. The rules and the add-client step are now shared with `POST /invoicing/payments/manual`.

- Invoicing profile: the profile's answer (GET and PUT /invoicing/profile)
  carries `next_numbers`, the next invoice number for every prefix in use,
  cancelled invoices counted (system_3 #12306). A profile save under a
  prefix that already has invoices no longer fails over the next number:
  the server sets it to one past the highest number issued and ignores the
  number sent, as the editor shows that field read-only. A prefix with no
  invoice still takes the number sent.

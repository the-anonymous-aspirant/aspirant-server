- **Build: a re-run of an older commit can no longer take `:latest`**
  (system_3 #9982, from #9966). Builds of main already ran one at a time
  (#4761), but a re-run or a dispatch of an older commit would still retag
  `:latest` with it and roll the server back on the next auto-pull. Now
  `:latest` and `:main` go only on a build of main's current head. Any other
  build pushes its `sha-` tag only. This is the same guard as
  aspirant-client #409.

- **Invoicing: a book per user, part 1 of 3** (system_3 #10059, from #10054,
  operator c62279). The issuer profile, the logo and the clients now belong
  to the signed-in user who made them, and each user sees only their own:
  another user's client reads as 404. Payments, tombstones and invoices gain
  the owner column and per-owner unique keys (invoice number; source and
  transaction id), whose queries follow in #10060 and #10061. The shared-book
  unique indexes are dropped at boot. Rows from before the column have owner 0,
  which no login has, and a request with no signed-in user is refused (401).
  Writes that must not interleave lock the user's row in
  `invoicing_owner_locks`, which exists whether or not a profile was saved,
  and a PayPal import matches clients only from the importer's own book.

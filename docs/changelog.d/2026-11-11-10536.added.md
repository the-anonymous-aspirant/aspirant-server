- A failed N26 or PayPal import upload (one that can't be parsed, or parses to zero usable rows) now gets a durable record and a time-limited copy of the file (system_3 #10536, security ruling c65222). The record holds metadata only (owner, time, filename, size, sha256, import kind, a fixed error message from a closed set — never the parser's own text, which can quote document values); the copy lives in a dedicated directory, never the database or an existing upload path, kept for up to 7 days and swept hourly, with failure rows themselves pruned after 90 days. Two new Admin-tier endpoints list recent failures and download a kept copy, each download audited.

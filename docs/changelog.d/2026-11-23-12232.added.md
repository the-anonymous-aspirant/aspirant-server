- **"Add payers…" gives an existing client the N26 payer's IBAN when it has
  none** (system_3 #12232). A ticked N26 row linked to a client already in the
  book now puts the row's IBAN on that client when every payment of the row
  carries the same one, the client has none, and no other client in the book
  has it, the same rule as for a new client and as the PayPal email follows.
  Later N26 payments from that account then link by themselves. The change is
  one client update whose audit row says only `iban_changed`. The candidates
  read gains `carries_iban` on a row and `has_iban` on `same_client`, both
  booleans; the IBAN itself is still never served.
